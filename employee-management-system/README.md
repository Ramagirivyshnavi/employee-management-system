# Employee Management System

A full-stack web application built to manage employee information and organize essential employee-related operations through a centralized interface.

## Features

- Employee CRUD operations (Create, Read, Update, Delete)
- Admin registration and login
- Dashboard for accessing application modules
- Department management
- Employee attendance management
- Leave management
- Responsive blue-and-white user interface

## Technologies Used

**Frontend:** React.js, Vite, JavaScript, HTML, CSS, Bootstrap, Axios

**Backend:** Java, Spring Boot, Spring Data JPA, REST APIs

**Database:** MySQL

## Project Modules

- Employee Management
- Admin Authentication
- Dashboard
- Department Management
- Attendance Management
- Leave Management

## Project Structure

- `ems-frontend` — React frontend
- `ems-backend` — Spring Boot backend

## Key Learnings

- Full-stack application development
- REST API integration
- CRUD operations
- Database connectivity using MySQL
- Frontend and backend integration
